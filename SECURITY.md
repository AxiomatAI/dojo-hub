# Security policy

Please report vulnerabilities privately via [GitHub Security Advisories](https://github.com/axiomat/dojohub/security/advisories/new). Do not open public issues for security problems.

We aim to acknowledge reports within 3 business days and to provide a fix or mitigation timeline within 10 business days.

Scope includes the server, web UI, CLI, Helm chart and container image. Scanner false negatives (a malicious skill that isn't flagged) are welcome as regular issues with a minimal, non-weaponised example.
